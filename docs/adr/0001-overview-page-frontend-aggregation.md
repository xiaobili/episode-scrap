# 概览页由前端聚合现有接口数据

概览页需要跨扫描、解析、刮削、重命名与任务中心展示进度。这些数据已经能从 `GET /api/files`、`GET /api/tasks`、`GET /api/settings`、`GET /api/datasources` 取得，因此概览页选择在前端聚合，不新增后端统计接口，也不引入活动流水（现有接口没有可靠的活动记录，硬做只能造假数据）。代价是每次进入概览页需要拉一次文件与任务列表；本工具的文件规模在千级，可以接受。

## Status

accepted

## Considered Options

- 新增 `GET /api/overview` 聚合接口：一次请求更省，但会改动后端与 API 契约，且计数口径会固化在服务端。
- 前端聚合：复用既有接口，计数口径与各业务页保持一致，后续调整概览展示不需要改后端。

## Consequences

- 概览页的计数完全依赖 `/files` 与 `/tasks` 的返回，二者字段变化会直接影响概览。
- 有运行中或等待中的任务时，概览页会每 12 秒轮询任务列表；任务结束后再补拉一次文件列表。离开页面即停止。
